# راهنمای قدم‌به‌قدم ساخت اپ در Android Studio

این راهنما برای کسی نوشته شده که **هیچ آشنایی قبلی با برنامه‌نویسی اندروید ندارد**.
فقط مراحل را به ترتیب انجام دهید. هر جا گیر کردید، بخش «۱۴) رفع مشکل» را ببینید.

زمان لازم: حدود **۱ ساعت** (بیشترش صرف دانلود می‌شود).
خروجی نهایی: یک فایل `app-release.apk` که روی گوشی خودتان نصب می‌کنید.

## ۱) چه چیزهایی لازم دارید

| مورد | توضیح |
|------|-------|
| کامپیوتر | ویندوز ۱۰/۱۱، مک یا لینوکس — حداقل ۸ گیگ رم، **۱۵ گیگ فضای خالی** |
| اینترنت | برای دانلود حدود ۳ تا ۵ گیگابایت (یک‌بار) |
| گوشی اندروید | اندروید ۸ (8.0) یا بالاتر، با کابل USB |
| حساب گوگل | لازم **نیست** (اپ را خودتان نصب می‌کنید، نه از Play) |

> **Java و Gradle را جداگانه نصب نکنید.** Android Studio خودش Java دارد و Gradle هم داخل پروژه هست.

## ۲) نصب Android Studio

1. برو به: **https://developer.android.com/studio**
2. دکمهٔ سبز **Download Android Studio** را بزنید و شرایط را Accept کنید.
3. فایل دانلودشده را اجرا کنید:
   - ویندوز: `android-studio-...-windows.exe`
   - مک: فایل `.dmg`
4. در نصب، همه‌چیز را **Next / پیش‌فرض** بگذارید. فقط اگر پرسید محل نصب، مسیر پیش‌فرض را قبول کنید.
5. بعد از نصب، Android Studio را باز کنید.
6. اولین بار یک پنجرهٔ **Setup Wizard** می‌آید:
   - گزینهٔ **Standard** را انتخاب کنید (نه Custom).
   - در صفحهٔ آخر **Accept** همهٔ مجوزها (licenses) را بزنید و **Finish**.
   - این مرحله چند گیگابایت دانلود می‌کند (SDK اندروید). صبر کنید تا تمام شود.

> اگر در ایران هستید و دانلود از `developer.android.com` یا `dl.google.com` گیر کرد، **VPN روشن کنید**
> (به بخش ۱۱ هم نگاه کنید).

## ۳) گرفتن فایل‌های پروژه

ساده‌ترین راه (بدون نصب هیچ برنامهٔ دیگری):

1. در مرورگر برو به صفحهٔ ریپازیتوری:
   **https://github.com/blackdown2022-ctrl/cmbtools**
2. دکمهٔ سبز **Code** را بزنید → **Download ZIP**.
3. فایل ZIP را **Extract** کنید در مسیری ساده و انگلیسی، مثلاً:
   ```
   C:\projects\cmbtools
   ```
   ⚠️ مسیر را داخل `Desktop` یا `Downloads` خیلی عمیق/فارسی انتخاب نکنید؛ مسیر کوتاه و انگلیسی امن‌تر است.
4. مطمئن شوید داخل پوشهٔ `cmbtools` این فایل‌ها را می‌بینید:
   ```
   settings.gradle.kts
   build.gradle.kts
   gradlew
   gradlew.bat
   app\
   gradle\
   ```
   اگر یک پوشهٔ اضافه مثل `cmbtools-main` داخل `cmbtools` بود، همان پوشهٔ داخلی را باز کنید (جایی که `settings.gradle.kts` هست).

## ۴) باز کردن پروژه

1. Android Studio را باز کنید.
2. در صفحهٔ خوش‌آمد، **Open** را بزنید (اگر پروژه‌ای باز است: منوی **File → Open**).
3. پوشه‌ای که `settings.gradle.kts` دارد را انتخاب کنید و **OK**.
4. اگر پرسید *Trust project?* → **Trust Project**.
5. حالا Android Studio شروع می‌کند به کار. **عجله نکنید** — پایین صفحه یک نوار پیشرفت با نوشتهٔ
   `Gradle Build Running` یا `Syncing` می‌بینید. اولین بار ۵ تا ۲۰ دقیقه طول می‌کشد.

## ۵) اولین Sync (مهم‌ترین مرحله)

در این مرحله Android Studio این‌ها را دانلود می‌کند: Gradle 8.7، کتابخانه‌های Compose/Room و ابزارهای اندروید.

**چه چیزی باید ببینید؟** پایین-چپ، تب **Build** بدون خطای قرمز، و در نوار وضعیت `Gradle sync finished`.

اگر پیام‌هایی مثل این دیدید، همان‌طور که گفته شده جواب دهید:

| پیام | پاسخ درست |
|------|------------|
| `Gradle JDK` / `Invalid Gradle JDK` | گزینهٔ **Embedded JDK (jbr-17)** یا **jbr-17** را انتخاب کنید |
| `Android Gradle Plugin update recommended` | **Don't remind me** (نسخه‌ها تست‌شده‌اند) |
| `Install missing SDK platform 34` | **Install** (اجازه دهید نصب کند) |
| `Gradle wrapper not found / use default gradle` | **Use Gradle from: gradle-wrapper.properties** |
| `SDK location not found` | بخش ۱۴، مورد ۱ |

> **نکته:** اگر دانلودها با خطای شبکه قطع شدند، یعنی مشکل اینترنت/فیلترینگ است → برو بخش ۱۱.

## ۶) آماده‌سازی گوشی

هدف: اجازه بدهیم کامپیوتر اپ را مستقیم روی گوشی نصب کند.

1. در گوشی: **Settings → About phone**
2. روی **Build number** هفت بار پشت‌سرهم بزنید تا پیام *You are now a developer* بیاید.
3. برگرد: **Settings → System → Developer options** (در شیائومی: Settings → Additional settings → Developer options)
4. **USB debugging** را روشن کنید.
5. کابل USB را وصل کنید (کابل **داده** باشد، نه فقط شارژ).
6. در گوشی پیام *Allow USB debugging?* می‌آید → **Allow** (تیک «Always allow» را بزنید).

**شیائومی/ردمی (MIUI) و برخی برندها:** علاوه بر USB debugging، این‌ها را هم روشن کنید:
- *Install via USB* (نصب از طریق USB)
- *USB debugging (Security settings)* — اگر خواست، حساب می‌خواهد.

## ۷) اجرای اپ روی گوشی

1. در بالای پنجرهٔ Android Studio، کنار دکمهٔ ▶ یک لیست کشویی هست؛ باید نام گوشی‌تان را ببینید
   (مثلاً `Pixel 6` یا `SM-A125`). اگر نبود، یک‌بار کابل را جدا/وصل کنید.
2. دکمهٔ سبز **▶ Run** را بزنید (یا `Shift + F10`).
3. اولین ساخت ۳ تا ۱۰ دقیقه طول می‌کشد. اگر گوشی پرسید *Install app?* → **Install**.
4. اپ با نام **حساب‌دفتر من** باز می‌شود. 🎉

اگر می‌خواهید بدون گوشی هم ببینید، می‌توانید از **Device Manager** (آیکون گوشی در نوار راست) یک
**Emulator** بسازید و همان‌جا اجرا کنید.

## ۸) تنظیمات اولین اجرا

هنگام باز شدن، اپ اجازهٔ **پیامک** و **نوتیفیکیشن** می‌خواهد → **Allow** (اجازه بدهید).

### ۸-۱) اطلاعات پنل هیدی‌فای

از پنل هیدی‌فای خودتان سه چیز بردارید:

| مقدار | از کجای پنل |
|-------|--------------|
| دامنه | آدرس پنل، بدون `https://` — مثلاً `panel.mydomain.com` |
| مسیر پروکسی ادمین | **تنظیمات → تنظیمات خیلی پیشرفته → مسیر پروکسی مدیران** (مثلاً `Ab3xY9`) |
| کلید API | **UUID ادمین** — همان UUID که در لینک پنل ادمین شما هست |

در اپ: **داشبورد → آیکون چرخ‌دنده (تنظیمات) → اتصال به پنل هیدی‌فای ۱۴** →
مقادیر را وارد کنید → **ذخیره و تست**.

- اگر نوشت «متصل • نسخهٔ 14.x» → همه‌چیز درست است ✅
- اگر خطا داد: مسیر پروکسی و کلید را دوباره چک کنید (بخش ۱۴، مورد ۶).

### ۸-۲) پیامک

در همان صفحه، بخش **پیامک**:

- **روش ارسال**:
  - *سیم‌کارت گوشی* → رایگان، مناسب شروع. فقط باید سیم‌کارت در گوشی باشد.
  - *درگاه پیامکی* → کلید API کاوه‌نگار یا SMS.ir + شمارهٔ خط را وارد کنید.
- **نام کسب‌وکار** (بالای فاکتور) و **امضای پیامک** را بنویسید → **ذخیرهٔ تنظیمات پیامک**.

### ۸-۳) اولین مشتری و اولین فاکتور (تست کامل)

1. تب **مشتریان** → دکمهٔ **+** → نام و موبایل و ۴ رقم آخر کارت (اختیاری) → **ذخیره**.
2. تب **فاکتور** → **+** → مشتری و بسته را انتخاب کنید → **صدور فاکتور**.
3. اگر «ساخت اکانت در پنل» روشن باشد، اکانت روی هیدی‌فای ساخته می‌شود و لینک اشتراک ثبت می‌شود.
4. در صفحهٔ فاکتور، **پیش‌نمایش و ارسال پیامک** را بزنید تا متن و هزینه/تعداد بخش را ببینید.

## ۹) ساخت APK نهایی (نصب دائمی)

نسخه‌ای که با ▶ Run نصب می‌شود «debug» است و برای استفادهٔ روزمره مناسب نیست. برای نسخهٔ نهایی:

### ۹-۱) ساخت Keystore (فقط یک‌بار در عمر پروژه)

1. منوی **Build → Generate Signed Bundle / APK…**
2. **APK** را انتخاب کنید → **Next**
3. جلوی *Key store path* روی **Create new…** بزنید و این‌ها را پر کنید:

   | فیلد | مقدار پیشنهادی |
   |------|-----------------|
   | Key store path | `C:\keys\cmbtools.jks` (جایی امن، غیر از پوشهٔ پروژه) |
   | Password / Confirm | یک رمز قوی — **جایی یادداشت کنید** |
   | Alias | `cmbtools` |
   | Key password | همان رمز بالا |
   | Validity | `25` سال |
   | Certificate | هر چیزی، مثلاً نام خودتان |

4. **OK** → **Next** → در صفحهٔ آخر **release** را انتخاب و گزینه‌های `V1` و `V2` را تیک‌دار بگذارید → **Create**.

### ۹-۲) فایل APK کجاست؟

```
app\release\app-release.apk
```
(Android Studio بعد از ساخت، یک اعلان با لینک **locate** نشان می‌دهد.)

### ۹-۳) نصب روی گوشی

1. فایل APK را با کابل/تلگرام به گوشی منتقل کنید.
2. روی فایل بزنید؛ اگر پرسید، برای آن فایل‌منیجر **Install unknown apps** را اجازه دهید.
3. اگر **Play Protect** هشدار داد (چون اپ مجوز پیامک دارد) → **Install anyway / نصب کن**.

> ⚠️ **مهم‌ترین نکته:** همیشه با **همان فایل keystore** امضا کنید. اگر عوض شود، اپ جدید روی قبلی
> نصب نمی‌شود و باید حذف/نصب کنید → **همهٔ دادهٔ مالی پاک می‌شود**. هر بار هم قبل از آپدیت،
> از **گزارش‌ها → پشتیبان کامل (JSON)** بکاپ بگیرید.

## ۱۰) آپدیت‌های بعدی

1. تغییرات جدید پروژه را بگیرید (Download ZIP جدید یا `git pull`) — **پوشهٔ `app` را جایگزین کنید**،
   نه کل پوشه (تا `local.properties` و تنظیمات IDE حفظ شود).
2. در فایل `app/build.gradle.kts` این دو خط را بالا ببرید:
   ```kotlin
   versionCode = 2          // هر بار +۱
   versionName = "0.1.1"    // نسخهٔ نمایشی
   ```
3. بکاپ بگیرید (گزارش‌ها → پشتیبان کامل).
4. دوباره **Build → Generate Signed APK** با **همان keystore** → نصب روی نسخهٔ قبلی.

## ۱۱) تنظیم پروکسی اگر دانلودها خطا داد

اگر Gradle با خطای `Could not resolve…`, `Read timed out`, `Connection reset` متوقف شد:

**راه ۰ (اگر خطای شما دربارهٔ پلاگین `com.android.application` بود):** اول بخش ۱۴ مورد **۳-الف** را ببینید؛
همان‌جا سه راه دقیق برای این خطا نوشته شده.

**راه ۱ (ساده):** VPN را روی کامپیوتر روشن کنید و Android Studio را ببندید و دوباره باز کنید.

**راه ۲ (اگر VPN روی پورت محلی است، مثلاً v2rayN با پورت 10809):**
فایل `gradle.properties` در پوشهٔ پروژه را با Notepad باز کنید و این چهار خط را اضافه کنید:

```properties
systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=10809
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=10809
```

بعد در Android Studio: **File → Sync Project with Gradle Files**.
(شمارهٔ پورت را از برنامهٔ VPN خودتان بردارید؛ v2rayN معمولاً 10809، کلش 7890.)

**راه ۳:** در Android Studio → **File → Settings → Appearance & Behavior → System Settings → HTTP Proxy**
→ گزینهٔ *Manual proxy configuration* → همان پورت.
بعد از پایان کار، پروکسی را خاموش کنید وگرنه ممکن است بعداً خطا بدهد.

> اگر همه‌چیز دانلود شد ولی بعداً اینترنت عوض شد، معمولاً مشکلی پیش نمی‌آید؛ Gradle فایل‌ها را کَش می‌کند.

## ۱۴) رفع مشکل (خطاهای رایج)

### ۱. `SDK location not found`
- **File → Settings → Languages & Frameworks → Android SDK** → مسیر SDK را ست کنید (معمولاً `C:\Users\<نام>\AppData\Local\Android\Sdk`).
- یا در ریشهٔ پروژه فایل `local.properties` بسازید:
  ```properties
  sdk.dir=C\:\\Users\\YourName\\AppData\\Local\\Android\\Sdk
  ```

### ۲. `Unsupported class file major version` یا `invalid source release`
- **File → Settings → Build, Execution, Deployment → Build Tools → Gradle** →
  *Gradle JDK* = **jbr-17 (Embedded JDK)**.

### ۳. `Could not resolve androidx...` / `Read timed out` / `Connection reset`
- مشکل اینترنت → بخش ۱۱.
- بعد از تنظیم پروکسی: **File → Invalidate Caches… → Invalidate and Restart** و دوباره Sync.

### ۳-الف. `Plugin [id: 'com.android.application', version: '8.5.2'] was not found in any of the following sources`

> 📄 نسخهٔ کوتاه و فقط برای همین خطا: [`fix-plugin-error-fa.md`](fix-plugin-error-fa.md)

این خطا **یعنی Gradle نتوانسته پلاگین اندروید را از `dl.google.com` دانلود کند**؛ پروژه سالم است.

به ترتیب این‌ها را امتحان کنید:

1. **VPN را روشن کنید** و در Android Studio: **File → Sync Project with Gradle Files** (آیکون 🐘 با فلش).
   بیشتر مواقع همین کافی است.
2. **پروکسی در Gradle:** فایل `gradle.properties` را با Notepad باز کنید، چهار خط زیر را از حالت
   توضیح خارج کنید (`#` ابتدایشان را بردارید) و پورت VPN خود را بگذارید:
   ```properties
   systemProp.http.proxyHost=127.0.0.1
   systemProp.http.proxyPort=10809
   systemProp.https.proxyHost=127.0.0.1
   systemProp.https.proxyPort=10809
   ```
   سپس Sync. (پورت: v2rayN → 10809، Clash → 7890)
3. **استفاده از آینه (بدون VPN):** در نسخهٔ جدید پروژه، آینه‌های `maven.aliyun.com` **از قبل بالای**
   `google()` هستند، پس Sync بدون VPN هم باید کار کند. کافی است **ZIP جدید `main`** را بگیرید.
   （اگر باز هم خطا داد، همان فایل `settings.gradle.kts` ترتیب مخازن را با توضیح فارسی در بالای خود دارد.）
4. **پروکسی خود Android Studio:** File → Settings → Appearance & Behavior → System Settings → HTTP Proxy
   → Manual → `127.0.0.1` و پورت VPN → OK → Sync.
5. اگر باز هم خطا داد، در ترمینال پایین Android Studio این را اجرا کنید و متن قرمز را بفرستید:
   ```bash
   ./gradlew --refresh-dependencies assembleDebug --stacktrace
   ```
   (ویندوز: `gradlew.bat --refresh-dependencies assembleDebug --stacktrace`)

> ⚠️ نکتهٔ مهم: اگر فایل ZIP را قبلاً دانلود کرده‌اید (پوشهٔ `cmbtools-main`)، نسخهٔ جدید `main` را
> دوباره دانلود کنید؛ نسخهٔ قدیمی فایل `gradlew` و چند اصلاح کامپایل را ندارد.

### ۴. `Gradle sync failed: Unsupported Android Gradle Plugin version`
- یعنی Android Studio شما قدیمی است. از **Help → Check for Updates** آپدیت کنید
  (نسخهٔ Ladybug 2024.2 یا جدیدتر لازم است).

### ۵. `Install failed: INSTALL_FAILED_UPDATE_INCOMPATIBLE`
- امضای APK جدید با نسخهٔ نصب‌شده فرق دارد. یا با همان keystore قبلی امضا کنید،
  یا اپ قبلی را حذف کنید (**داده پاک می‌شود → اول بکاپ**).

### ۶. پنل وصل نمی‌شود
- `مسیر پیدا نشد / 404` → مسیر پروکسی ادمین اشتباه است (بدون `/` اول و آخر بنویسید).
- `دسترسی رد شد / 401` → کلید API اشتباه است؛ باید **UUID ادمین** باشد نه پسورد.
- `دامنه پیدا نشد` → VPN/اینترنت یا دامنهٔ اشتباه.
- `خطای گواهی SSL` → اگر پنل گواهی معتبر ندارد، در اپ گزینهٔ **HTTPS** را خاموش نکنید؛ بهتر است
  گواهی پنل را درست کنید.

### ۷. پیامک بانکی خوانده نمی‌شود
- مجوز پیامک را چک کنید: **Settings → Apps → حساب‌دفتر من → Permissions → SMS → Allow**.
- بعضی گوشی‌ها (شیائومی/هواوی/سامسونگ) اپ را در پس‌زمینه می‌کشند:
  **Settings → Apps → حساب‌دفتر من → Battery → Unrestricted** و در MIUI *Autostart* را روشن کنید.
- اپ باید **یک‌بار باز شده باشد** تا گیرندهٔ پیامک ثبت شود.

### ۸. اپ باز می‌شود ولی صفحه سفید است
- **Build → Clean Project** و سپس **Rebuild Project**. اگر ادامه داشت، تب **Logcat** را ببینید و
  متن خطای قرمز را برایم بفرستید.

### ۹. هر خطای دیگری
در Android Studio پایین صفحه تب **Build** (یا **Logcat**) را باز کنید، متن قرمز را **کپی** کنید و برایم بفرستید.
همین‌طور خروجی این دستور را (در ترمینال پایین Android Studio):
```bash
./gradlew assembleDebug --stacktrace
```
(در ویندوز: `gradlew.bat assembleDebug --stacktrace`)
