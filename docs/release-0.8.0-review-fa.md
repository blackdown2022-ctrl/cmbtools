# بررسی مبلغ پیامک و دریافت سفارش‌ها — نسخهٔ ۰.۸.۰

## علت فنیِ مبلغ اشتباه در نسخهٔ پیشین

پارسر قبلی اولین عددِ دارای پسوند ریال/تومان را برمی‌داشت؛ بنابراین اگر پیامک موجودی را پیش از مبلغ تراکنش نوشته بود، موجودی می‌توانست به‌جای مبلغ واریز انتخاب شود. برای SMSهای بدون واحد نیز از حد آستانهٔ یک‌میلیون برای حدس ریال/تومان استفاده می‌شد؛ این حدس برای مبلغ‌های بزرگ می‌توانست تبدیل را ده‌برابر اشتباه کند.

این نسخه کاندیداهای مبلغ را با واژه‌های مجاور مثل «واریز/مبلغ» در برابر «موجودی/مانده» امتیازدهی می‌کند و مبلغ تراکنش را از موجودی جدا می‌سازد. ریال/تومانِ صریح تبدیل می‌شود. اگر خود پیامک واحد پول را ننوشته باشد، مقدار محلی همچنان به‌عنوان تخمین نمایش داده می‌شود، ولی نه برای تطبیق خودکار دفتر و نه برای ارسال به ربات استفاده می‌شود؛ پیامک در انتظار بازبینی می‌ماند و تب «آزمایش» علت را نشان می‌دهد. پیامک‌های قدیمیِ هنوز بی‌تطبیق نیز با پارسر جدید بازخوانی می‌شوند؛ پرداخت‌های قبلاً ثبت‌شده دست‌نخورده می‌مانند. اگر پیامک شما واحد ندارد، برای افزودن قاعدهٔ دقیق بانک به نمونهٔ واقعی و بی‌اطلاعات حساس آن نیاز است.

## چرا سفارش‌های تازه به‌صورت فهرست به اپ نمی‌آیند؟

API فعلی سرور salebot برای اپ فقط این‌ها را دارد:

- `POST /wp-json/webdide-cv/v1/confirm` برای ارسال مبلغ و کد پیگیری از اپ به سرور؛
- `GET /wp-json/webdide-cv/v1/status?order_id=...` برای خواندن وضعیت **یک شناسهٔ معلوم**؛
- `GET /wp-json/webdide-cv/v1/health` برای آزمایش اتصال.

در API Shetab هیچ مسیر مجاز برای فهرست‌کردن سفارش‌های تازه با Secret اپ وجود ندارد. فهرست مدیریتی Mini App احراز هویت تلگرام (`X-Telegram-Init-Data`) می‌خواهد و Secret اپ جایگزین آن نیست. بنابراین اپ نمی‌تواند بدون تغییر سرور، سفارش‌های تازه را خودکار دریافت/فهرست کند؛ مسیر status فقط با شناسهٔ سفارش کار می‌کند. برای دریافت فهرست باید در خود salebot یک endpoint خواندنیِ جدید با احراز هویت Secret اضافه و آن نسخه روی سرور شخصی کاربر نصب شود. در این نسخه endpoint خصوصی جدیدی جعل یا فرض نشده است.

## تغییرات اپ

- افزودن واحد پول استخراج‌شده به تشخیص: `RIAL`، `TOMAN` یا واحد حدس‌زده‌شده.
- انتخاب مبلغ بر پایهٔ عبارت تراکنش، نه اولین عدد دارای پسوند پولی؛ تستی که موجودی قبل از مبلغ واریز آمده را پوشش می‌دهد.
- مسدودکردن تطبیق خودکار دفتر و ارسال ربات برای SMS بی‌واحد تا وقتی قالب بانک و واحد واقعی روشن شود؛ این محافظ از تأیید مبلغ نادرست جلوگیری می‌کند.
- بازخوانی پیامک‌های تاریخیِ بی‌تطبیق هنگام اجرای اپ با قواعد تازه، بدون دست‌زدن به پرداخت‌های ثبت‌شده.
- ذخیرهٔ واحد تشخیص‌داده‌شده و نمایش آن در گزارش آخرین SMS.
- حفظ تب وضعیت سفارش برای پرس‌وجوی دستی بر اساس شناسه.
- نسخه `0.8.0`، `versionCode=14`.
