# بازگشت قابلیت‌ها به پیش از افزودن ربات — نسخهٔ ۰.۸.۲

به درخواست کاربر، کد برنامه به وضعیت قبل از ادغام PR شمارهٔ ۲۲ (`900e5e7` / انتشار `v0.5.1-50`) بازگردانده شد. قابلیت‌های افزوده‌شده پس از آن در این بازگشت حذف شده‌اند؛ از جمله:

- صفحه و تنظیمات اتصال/تأیید پرداخت ربات، API client و Worker پس‌زمینه؛
- صف و گزارش‌های مخصوص ربات؛
- اصلاحات parser و allowlist سرشماره‌ای که پس از اضافه‌شدن ربات ساخته شده بودند.

مسیر عادی دریافت و تطبیق پیامک بانکی، حسابداری، پنل، فاکتور و پشتیبان‌گیری طبق کد پیش از ربات باقی مانده است. Secret و کلیدهای گزارش باقی‌مانده از نسخهٔ ربات در شروع این نسخه از تنظیمات رمزگذاری‌شدهٔ دستگاه پاک می‌شوند.

برای اینکه این نسخه روی نصب فعلی `0.8.1` بدون حذف برنامه و داده‌ها نصب شود، شمارهٔ نمایش `0.8.2` و `versionCode=16` نگه داشته شده است؛ محتوای قابلیت‌ها به نسخهٔ پیش از ربات برگشته است. از داده‌ها نسخهٔ پشتیبان بگیرید و APK تازه را روی نسخهٔ فعلی نصب کنید.
