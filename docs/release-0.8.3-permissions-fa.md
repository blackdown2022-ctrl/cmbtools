# درخواست اجازهٔ پیامک و اجرای پس‌زمینه در اولین ورود — نسخهٔ ۰.۸.۳

- در اولین ورود به صفحهٔ اصلی، توضیح کوتاهی پیش از درخواست اجازه‌ها نمایش داده می‌شود.
- مجوز زمان اجرای `SEND_SMS` برای ارسال فاکتور با سیم‌کارت درخواست می‌شود.
- اگر اندروید اجازه دهد، سپس صفحهٔ سیستمیِ خارج‌کردن اپ از محدودیت بهینه‌سازی باتری باز می‌شود تا همگام‌سازی پس‌زمینه کمتر متوقف شود.
- انتخاب «بعداً» یا رد هر اجازه، اپ را قفل نمی‌کند و درخواست خودکار را تکرار نمی‌کند. در تنظیمات → پیامک می‌توان مجوز ارسال پیامک را دوباره درخواست کرد؛ در تنظیمات → همگام‌سازی نیز مسیر فعال‌کردن اجازهٔ پس‌زمینه وجود دارد.
- اندروید اجازه را فقط با تأیید خود کاربر می‌دهد؛ برنامه نمی‌تواند آن را مخفیانه/خودکار اعطا کند. بعضی سازندگان گوشی تنظیم جداگانهٔ «شروع خودکار/اجرای پس‌زمینه» دارند و باید آن را نیز در تنظیمات خود گوشی فعال کرد.

نسخه: `0.8.3`، `versionCode=17`.
